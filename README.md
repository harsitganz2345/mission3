# VideoBelajar Frontend

Project ini dibuat dari export frame Figma yang diberikan.

## Teknologi
- HTML
- CSS
- JavaScript vanilla

## Tidak digunakan
- Backend/server
- Database
- localStorage/sessionStorage
- API autentikasi

## Halaman
- `index.html` — Home
- `login.html` — Login
- `register.html` — Register
- `forgot-password.html` — Lupa Password
- `reset-password.html` — Reset Password

## Menjalankan
Buka `index.html` atau `login.html` langsung di browser. Untuk development, bisa juga menggunakan Live Server di VS Code.

Semua login/register/reset masih simulasi karena tidak ada penyimpanan data.
